# Win Cleaner by mysik

Очистка и настройка Windows в одном окне: освобождает место, убирает рекламу и лишнее из автозагрузки. Каждое изменение можно вернуть обратно.

**Страница программы и скачивание:** https://mysik-portfolio.vercel.app/soft/win-cleaner.html

## Что умеет

- **Очистка** — временные файлы, кеш обновлений, отчёты об ошибках, миниатюры и корзина.
- **Кеш браузеров** — пароли, история и вкладки при этом остаются.
- **Без рекламы** — убирает «советы» и рекомендации в Пуске, Bing из поиска, Copilot.
- **Настройки Windows** — телеметрия, старое меню правой кнопки, Game Bar, расширения файлов, ускорение мыши.
- **Автозагрузка** — отключение как в Диспетчере задач: программа остаётся и включается обратно одним нажатием.
- **Точка восстановления** — можно создать перед изменениями одной кнопкой.

## Как начать

Нужна только Windows 10 или 11 — компилятор .NET Framework 4.x уже встроен в систему.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, и распакуйте.
2. Запустите `build.bat` — через пару секунд рядом появится `WinCleaner.exe`.
3. Откройте `WinCleaner.exe`. Разрешите права администратора: без них программа не сможет работать.
4. **Нажмите «Сканировать».** Программа покажет, сколько места занимает мусор.
5. **Отметьте нужное.** Удаляется только отмеченное, временные файлы младше суток не трогаются.

Файлы: `MainWindow.xaml`, `README.txt`, `Shell.cs`, `Theme.xaml`, `WinCleaner.cs`, `app.ico`, `app.manifest`, `build.bat`.
