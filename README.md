# Win Cleaner by mysik

Очистка и настройка Windows в одном окне: освобождает место, убирает рекламу и лишние программы из автозагрузки. Каждое изменение можно вернуть обратно.

## Очистка

Показывает, сколько места занимает мусор, и удаляет только отмеченное:

- временные файлы (младше суток не трогаются)
- кеш обновлений Windows
- кеш браузеров — пароли, история и вкладки остаются
- отчёты об ошибках и дампы памяти
- кеш оптимизации доставки и миниатюр
- корзина

## Настройки Windows

Переключатели, каждый можно выключить обратно:

- убрать рекламу, «советы» и рекомендации в Пуске
- отключить телеметрию
- убрать Bing из поиска в Пуске
- отключить Copilot
- старое меню правой кнопки (Windows 11)
- отключить запись игр Xbox Game Bar
- схема питания «Высокая производительность»
- показывать расширения файлов
- отключить ускорение мыши и залипание клавиш
- быстрые меню

Перед изменениями можно нажать **«Точка восстановления»**.

## Автозагрузка

Список программ, которые стартуют вместе с Windows, с переключателями. Отключение работает так же, как в Диспетчере задач: программа остаётся на компьютере и включается обратно одним нажатием.

## Запуск

При запуске разрешите права администратора — без них не почистить системные папки.

## Сборка

Нужна только Windows 10 или 11 — компилятор .NET Framework 4.x уже встроен в систему.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, и распакуйте.
2. Запустите `build.bat` — за несколько секунд рядом появится `WinCleaner.exe`.
3. Перенесите `WinCleaner.exe` куда удобно и запускайте.

Файлы в репозитории: `WinCleaner.cs`, `Shell.cs`, `MainWindow.xaml`, `Theme.xaml`, `app.manifest`, `app.ico`, `build.bat`.
