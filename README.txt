WIN CLEANER by mysik
====================

Очистка
-------
Показывает, сколько места занимает мусор, и удаляет отмеченное:
временные файлы, кеш обновлений Windows, кеш браузеров (пароли, история
и вкладки остаются), отчёты об ошибках, кеш оптимизации доставки,
кеш миниатюр и корзину. Временные файлы младше суток не трогаются.

Настройки Windows
-----------------
Переключатели, каждый можно вернуть обратно:
• убрать рекламу, «советы» и рекомендации в Пуске;
• отключить телеметрию;
• убрать Bing из поиска в Пуске;
• отключить Copilot;
• старое меню правой кнопки (Windows 11);
• отключить запись игр Xbox Game Bar;
• схема питания «Высокая производительность»;
• показывать расширения файлов;
• отключить ускорение мыши;
• отключить залипание клавиш;
• быстрые меню.
Перед изменениями можно нажать «Точка восстановления».

Автозагрузка
------------
Список программ, которые стартуют вместе с Windows, с переключателями.
Отключение работает так же, как в Диспетчере задач: программа остаётся
на компьютере и включается обратно одним нажатием.


Сборка и запуск
---------------
1. Распакуй архив, проверь, что все файлы лежат рядом
   (WinCleaner.cs, Shell.cs, MainWindow.xaml, Theme.xaml, app.ico,
   app.manifest), и запусти build.bat.
2. Запусти WinCleaner.exe и разреши права администратора:
   без них не почистить системные папки.
